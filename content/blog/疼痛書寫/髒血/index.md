〈髒血〉
{{< spacer >}}
經過兩天發炎、發燒的身體反應{{< spacer >}}
最終還是從極大的痛苦中活了下來{{< spacer >}}
彷彿一次重生{{< spacer >}}
{{< spacer >}}
每當疤痕開始疼痛、發炎、化膿、流血、結痂{{< spacer >}}
這種時候{{< spacer >}}
我感到特別的{{< spacer >}}
特別的病態、脆弱、想消失{{< spacer >}}
{{< spacer >}}
那種痛不欲生的感覺{{< spacer >}}
來自發炎的位置在疤痕底下{{< spacer >}}
無法觸及之處{{< spacer >}}
只能等著發炎反應結束{{< spacer >}}
感受身體的白血球正在殺死細胞{{< spacer >}}
成群結隊的細胞大戰在體內發生{{< spacer >}}
疼痛著、發炎著{{< spacer >}}
被稱之為感染的反應{{< spacer >}}
刺痛、脹痛與無法停止的痛{{< spacer >}}
{{< spacer >}}
直到細胞殺死了細胞{{< spacer >}}
刺破了外表的囊皮{{< spacer >}}
流出細胞的屍體與屍水{{< spacer >}}
{{< spacer >}}
染紅了手{{< spacer >}}
染紅了浴缸{{< spacer >}}
流了足夠的血液與體液{{< spacer >}}
我竟感到滿足{{< spacer >}}
今夜終於可以睡覺{{< spacer >}}
發燒終於漸漸退去{{< spacer >}}
{{< spacer >}}
我想到女性月經的身體經驗{{< spacer >}}
身體的出血伴隨疼痛出現{{< spacer >}}
這樣的經驗最初是否也有一種病態/生病的感覺？{{< spacer >}}
（然而我有生病嗎？）{{< spacer >}}
{{< spacer >}}
背後的原因之一也是{{< spacer >}}
我們害怕自己的血{{< spacer >}}
害怕自己身上流出溫熱的血液{{< spacer >}}
害怕自己失去了象徵生命的血液{{< spacer >}}
{{< spacer >}}
從何時開始女性不再害怕自己的月經？{{< spacer >}}
從何時開始我也不再害怕自己的血液了{{< spacer >}}
{{< spacer >}}
盡情地讓血流出{{< spacer >}}
讓身體變得乾淨{{< spacer >}}
似乎呼應某種自傷的情境{{< spacer >}}
我看著滿手的血如此盼望{{< spacer >}}
讓骯髒的血離開{{< spacer >}}
讓乾淨的血重生{{< spacer >}}
讓疼痛的我消失{{< spacer >}}
讓疼痛的我重生{{< spacer >}}
