### 〈疼痛是比較級的〉
{{< spacer >}}
這個疼痛有多痛？{{< spacer >}}
我必須仰賴另一個疼痛經驗{{< spacer >}}
才能說明{{< spacer >}}
⁡{{< spacer >}}
疼痛/受苦的語言{{< spacer >}}
疼痛/痛苦的認識論{{< spacer >}}
具有比較的性質{{< spacer >}}
⁡{{< spacer >}}
我如何理解自己的疼痛/受苦{{< spacer >}}
某一部分是來自比較{{< spacer >}}
這也是我們連結這個世界的途徑{{< spacer >}}
⁡{{< spacer >}}
正是因為{{< spacer >}}
自己的痛苦屬於自己{{< spacer >}}
他人的痛苦專屬他人{{< spacer >}}
這個專屬特性是確定的、絕對的{{< spacer >}}
我們才能在彼此之間{{< spacer >}}
產生張力{{< spacer >}}
產生意義{{< spacer >}}
⁡{{< spacer >}}
如果每個人的疼痛都一樣{{< spacer >}}
就沒有意義了{{< spacer >}}
如果每一次的疼痛都一樣{{< spacer >}}
我就沒辦法說明有多麼痛了{{< spacer >}}
⁡{{< spacer >}}
正是因為疼痛是一個普遍的經驗{{< spacer >}}
所以我才可以告訴你我的痛{{< spacer >}}
讓你理解我的痛{{< spacer >}}
你也用你痛的歷史{{< spacer >}}
來理解{{< spacer >}}
我痛的歷史（短時間也算）{{< spacer >}}
⁡{{< spacer >}}
「比較」意味著歷史的比較{{< spacer >}}
我在跟過去的經驗比較{{< spacer >}}
也在跟他人的經驗比較{{< spacer >}}
⁡
—寫於2023年11月17日半夜
