### 〈疼痛是鬼〉
{{< spacer >}}
疼痛是鬼{{< spacer >}}
它一直都在{{< spacer >}}
不可見{{< spacer >}}
不可知{{< spacer >}}
不可觸碰{{< spacer >}}
但我知道它一直都在{{< spacer >}}
{{< spacer >}}
我稱疼痛為鬼{{< spacer >}}
將人拉入暗處{{< spacer >}}
吞噬、嚥下、吐出{{< spacer >}}
成了盲聾的你{{< spacer >}}
{{< spacer >}}
看不見形體{{< spacer >}}
聽不見哭聲{{< spacer >}}
鬼正在我的身上{{< spacer >}}
靈異（疼痛）體質的緣故{{< spacer >}}
醫生說{{< spacer >}}
我們需要好幾年才趕鬼{{< spacer >}} 
（可我沒有那麼多時間）{{< spacer >}}
{{< spacer >}}
踏入一片陰影{{< spacer >}}
意義感剝離{{< spacer >}}
存在感浮現{{< spacer >}}
疼痛是鬼{{< spacer >}}
它一直都在{{< spacer >}}
它無所不在{{< spacer >}}
